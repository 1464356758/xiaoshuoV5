# 新小说初始化母版 V4.6.2 · XS-KU 实库修正版

已绑定 https://github.com/1464356758/XS-KU 。新书仓库保存本书正文；XS-KU提供参考原文、教材、阅读进度和练习。无需模型API密钥。

1. 把包内文件上传到一个独立的新小说仓库，发送仓库链接和《启动新书.txt》。已有作品按真实状态恢复，不覆盖重建。
2. 先选择平台，核查规则、榜单及适配样本，再提出5—10个原创选题，等作者选择。
3. GPT按当前创作问题查参考库最新目录、实际阅读所需原文，把适用写法转为本书人物的欲望、行动、办法和代价。
4. 作者选题后建立设定、人物知情与资源事实账、长期路线及近期3—5章安排；授权“开始写”后写首章。
5. 每章任务书绑定真实教材提交和原文定位；写后在同一release报告核对实际效果、原创性和本章引文。采用后冻结。
6. 后续只需说“下一章”，每次完成一章至冻结、提交和回读。平台发布另凭真实回执登记。

所有新章统一目标6000汉字、允许5500—6500，包括前五章。保留约90万汉字体量，默认150章。旧书保留已冻结内容和已有配置。

开始先读docs/XS-KU接入与创作.md。reference_library/XS-KU.json记录本次交付的171份原文目录画像及12条教材；索引不等于通读，当前正式目录与新上传内容以参考库最新版本为准。

包内没有其他小说的正文、book_id、写作进度或定时任务。个人管理端与代发端需使用同版本部署包；本次打包不表示既有网址已经升级。定时写作只在作者明确要求后实际配置。

新书前五章启用《前五章投稿验收.md》：写前整体设计，精读两部独立开篇各至少一万汉字，逐章累计全文审读，第三/第五章样稿复核。每章目标6000汉字；不以字数或程序通过冒称平台签约。
