# 新书平台目录与热度

工作台1.4.4个人端“新书指令”收录作者提供的《中国小说投稿签约平台对照_2026-10-24.xlsx》42条入口，并保留《十平台试投与换书方案_2026-10-24-1.md》中的点众文学，共43个品牌、频道或专项入口。同一品牌下的频道分别可选，不代表43家独立公司。

支持平台全称、简称、拉丁字母别名及题材关键词搜索，统一全角半角和大小写，空格分隔的关键词须同时匹配。例如“SF”“菠萝包”“17K”“花语 女频”“短篇”。可按热度参考或名称排列；搜索、清空、无结果和切换排序都保留已选平台，只有主动更改选择才改变指令。未选平台时继续保留等待作者选择的开书流程。

## 热度口径

使用QuestMobile《2026短剧行业洞察报告》第5页的2026年2月数字阅读App月活跃用户数据，核查日期2026-10-31。

| 本目录可比名次 | 阅读App | 月活跃用户（万） |
| --- | --- | ---: |
| 1 | 番茄免费小说 | 25,988 |
| 2 | 七猫免费小说 | 8,610 |
| 3 | 掌阅 | 4,090 |
| 4 | QQ阅读 | 2,680 |
| 5 | 起点读书 | 1,936 |
| 6 | 书旗小说 | 1,920 |

这是本目录中有同口径数据的6项的相对顺序，非实时全行业完整榜单。官网流量、移动App月活、付费人数和母集团用户数不能混排。短故事、女生频道和其他专项入口不继承母App名次；没有同口径数据的其余37项明确标为“暂无可比热度”，按名称排列。

来源：[QuestMobile官方报告](https://www.questmobile.com.cn/research/report/2041710682848727041/)；[报告数据表，第5页](https://pdf.dfcfw.com/pdf/H3_AP202605271822903507_1.pdf#page=5)。流量不能推导作者收入、签约机会或平台AI稿件政策。

## 初始化目录

`platforms.json`保存研究入口和稳定编号，保留原有qidian、fanqie、qimao、jinjiang编号；网页目录与其43项一一对应。作者入口取自附件，不是对当前入口可用或现行合同的再次认证。快点仅有附件中的应用商店入口，官方域名与投稿入口待核；新增项未核实榜单网址时留空。选定后仍须按《平台研究与选题.md》核查当前官方域名、收稿规则、AI政策和真实榜单，记录时间与来源。试投优先级不作为热度分数。

个人端与最新初始化包均包含目录和搜索模块。代发页继续使用原有阅读流程。此次更新不改小说清单、正文或任何定时任务。
