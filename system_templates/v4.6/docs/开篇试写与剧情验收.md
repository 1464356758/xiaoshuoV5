# 开篇试写与剧情验收

开篇试写、结果检查和前三章复核沿用已有的选题、写作任务书和发布前检查。作者继续使用「开始写」和「下一章」指令。

已接入小说库时，先按《小说参考库.md》比较目标题材的整书、开篇及阶段教材，并回读原文。开篇试写使用全新的本书前提，作者认可的原创安排写入现有任务书。原作对照练习保存在小说库，后续用全新题目及真实读者、平台反馈验证迁移效果。

## 选题与试写

1. 优先比较同平台、同题材作品。记清实际读到哪里，首个可见结果出现在哪里。只有简介或榜单时，把开篇写法列为待核实。
2. 在候选的读者承诺里写明首章的行动结果、第二章由此产生的代价或反击、第三章回答的短期问题。可用一次小胜、一次关键损失、一次关系变化或一条已被证实的线索作为结果。
3. 选题并获得写作授权后，试同一前提的两种原创开场，各约300—800汉字。保留草稿，比较哪里会让读者停下、哪个问题能推动读者继续读。在原任务书中写明选用的开场方向及理由，随后写完整章。
4. 前三章建议每章2500—3500汉字，默认上限4500。第4章起按本书连载配置。开启严格字数的连载在采用前会按已冻字数和剩余章节核算本章可用字数。章长以现行任务书和检查结果为准，发现预算不足时先调整本章场景，再采用。

## 用一份发布前检查判断结果

在原任务书中说清主角当下的目标、选择及预计发生的结果。成稿后先读正文，再对照大纲。

- **首章检查。** 在现有开篇引文中用题材承诺和主角实际处境变化作证。前3000汉字应出现一次与卖点直接相连的结果。另在实际场景中引用导致结果的行动。
- **每章检查。** 用现有实际场景、读者承诺兑现和续读理由解释主线怎样推进。回查最容易被跳过的段落，删或合并重复说明，保留能改变情绪、关系、理解或决定的细节。
- **第三章检查。** 一起读前三章原文。在现有读者审读中说明首个短期问题的答案、可见结果和下一问，附对应引文。发布前报告已有前三章的正文版本覆盖。
- **返修。** 只有手续而无实质结果、主线被绕行冲淡、短期问题仍悬空等会影响续读的问题，写入原 reader.issues，标 must_fix，留原文依据。在当前候选中处理后重新核验。同一任务最多三轮。

例如，经商开篇写了接铺、点货、议价和验样，结尾还在等订单。若读者承诺是靠本领翻身，应让一次独到判断引出已验收的小单，或其他能改变处境的实际结果。求生故事中，破封、认责和等待搬运可以保留在因果链里，但真正的救援结果来自处境已经改变。

脚本校验章长、引用位置、报告版本和阻断状态。审读者依据正文判断所引用的结果是否兑现卖点。
