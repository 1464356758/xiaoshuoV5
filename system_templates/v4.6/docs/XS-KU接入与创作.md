## 开书时实际怎么做

1. 读取本书project_config、reference_library/XS-KU.json，以及参考库main最新catalog。该配置里的profile是交付快照，新上传原文以最新目录为准。
2. 根据作者选择的平台、题材与想要的阅读体验，查教材和候选书。平台信息尚未核实的书先按题材和实际内容比较，在当前平台榜单研究中补核适配性。
3. 回读相近样本的实际开篇和必要前后文，再提出原创候选。每题说明本书特有的欲望、处境、优势的边界、前三章的选择与结果，以及后续怎样持续产生变化。标清参考依据和阅读范围。
4. 作者选题后，设计本书关键转折和近期3—5章。参考整书或阶段结构时，实际阅读所需范围，记录待核部分。具体人物组合、连续事件和解决办法按本书动机重建。

## 每章把参考用到哪里

先说清这一章最重要的创作难题。例如「双方为什么都不肯让步」「一次进展怎样改变关系」「技能进步怎样在现场被看见」。检索与这个问题匹配的教材，回读原文证据，选择本书能够成立的做法。

导出的摘要保留参考库版本、原文件路径、原文件Git哈希、证据位置及引文哈希。把它放在新书的drafts或research资料目录，通过brief-request --references创建原任务书。references.application写这一章实际安排，references.originality写本书角色为什么如此行动、解决办法及代价。

writer资料只使用这些为本书准备的自然语言安排。写完后在原release报告的narrative_review.reference_use填写application_observed、originality_review及本章正文引文，检查所学有没有真正写出来。缺少这些证据会挡住本次采用，其他问题继续放进原reader.issues处理。新报告与正文、任务书版本绑定。

## 如何取得原文与恢复阅读

可运行联网Git的工作区，先将XS-KU检出到小说正文目录外。读取已提交catalog、books和studies，按本章问题选择材料。新增小说或原文改版后运行下面的同步命令，逐本核对已提交原文。

```bash
python3 新书工具目录/novel_library.py --root XS-KU实际检出目录 sync --repository-url https://github.com/1464356758/XS-KU
python3 新书工具目录/novel_library.py --root XS-KU实际检出目录 search --query "关系 主动选择 代价"
python3 新书工具目录/novel_library.py --root XS-KU实际检出目录 read --book 实际编号 --chapter 实际单元序号
```

输入按Git原文文件识别，包括根目录和incoming目录中的无后缀书籍。教材检索先返回已完成记录，也提供匹配的候选原文。查不到合适教材时，选择候选书实际阅读，补建本轮需要的记录。

工作区暂时无法联网时，使用已连接GitHub读取catalog和所选books记录。书籍清单采用gzip-base64保存索引，按声明格式解码即可得到原文位置。随后固定到source_origin.commit，按path及raw_start_line/raw_end_line读取原文，整理方法以工具为准。原文行较长时继续按该单元的raw_start_char/raw_end_char控制范围；分批读取须记录覆盖。只取得部分材料时，写作依据也按实际范围表述。

阅读书签保存在catalog对应书籍的reading_position。完成拆书后由study-check保存带证据记录。对照练习先保存稿件再复盘，mode与反馈来源按实际填写。同一书的多个版本使用同一family_id，验证全新题目时避免把同书另一版本当成独立样本。

## 新书与参考库的文件分工

XS-KU保存原文、目录、阅读进度、拆书和练习。新书仓库保存自己的设定、路线、正文、正式任务书和审读记录。每次工具维护与进度更新按当前远程头非强制提交并回读。作者继续使用「开始写」「下一章」，每次完成一章至冻结，发布由实际回执另行登记。

具体工具字段、拆书与练习命令见docs/小说参考库.md。正文的一致性、事实与因果仍需实际审读，专业事实另查可靠来源。学习记录、模型评价、真实读者反馈与平台结果各自保留实际来源。

## V4.6最终接线

在实际可运行Git的工作区，先取得参考库当前默认分支；使用下列入口会核对本书绑定、库身份、真实提交及原文证据，不改参考库正文或阅读进度：

```bash
python3 tools/reference_bridge.py --project . --library ../XS-KU prepare --query "关系 主动选择" --platform 七猫 --out drafts/本章教材.json
python3 tools/novel_state.py --root book brief-request --references drafts/本章教材.json --out drafts/本章任务书.json
```

自动命中的教材仍由GPT回读核对适用性，不能把程序引文匹配算成已经理解全书。需要指定教材时可重复传入--study实际编号。查无结果就实际阅读候选书、登记新教材并提交后再导出，不使用空教材绕过绑定。

搜索会保留平台待核的候选并标记unverified，已知属于其他平台的样本不当成当前平台依据。同书多个原文版本按family_id去重为一个候选，不能把重复版本当作独立市场样本。题材提示来自文件名推断，具体适配需看内容。

在线export将比较所填提交中的目录、教材、练习和原文版本；未提交改动与编造提交会拒绝导出。初始包保留固定画像，后续查库仍读实际最新目录。

原release报告新增reference_use的outcome为applied、adapted或not_used，必须说明application_observed及originality_review，并用当前章evidence佐证。not_used用于实际不适合的教材，需解释原因。参考材料不能强迫本书复制原作事件。
